# 🚀 대학생 맞춤형 팀원 매칭 플랫폼 (Team Matching Platform)

> **"기술 스택을 넘어 협업 스타일까지 일치하는 최적의 팀원을 만나보세요."**

## 📌 1. 프로젝트 개요 (Motivation)
학부 프로젝트 및 캡스톤 디자인 진행 시, 팀원의 기술 스택뿐만 아니라 실제 협업 스타일(가용 시간, 학점 목표 등)의 불일치로 발생하는 갈등과 효율 저하 문제를 해결하고자 합니다.
사용자 프로필 데이터 기반의 필터링 및 매칭 알고리즘을 통해 최적의 팀 빌딩을 지원합니다. 

## 🛠 2. 기술 스택 (Tech Stack & Rationale)
| 구분 | 기술 스택 | 선정 이유 |
| :--- | :--- | :--- |
| **Frontend** | **React.js** | 컴포넌트 기반 UI 개발 및 효율적인 상태 관리 지원
| **Backend** | **Spring Boot** | REST API 서버 구축 및 안정적인 비즈니스 로직 처리 
| **Database** | **PostgreSQL** | 사용자 및 팀 관계 데이터 저장에 최적화된 RDBMS 
| **Container** | **Docker** | 개발 및 운영 환경의 일치화(Immutable Infrastructure)
| **CI/CD** | **GitHub Actions** | 자동 빌드, 테스트 및 배포 파이프라인 구축 

## ✨ 3. 핵심 요구사항 (Key Features)
* **회원 관리:** 학교 계정 인증 및 상세 프로필(관심 분야, 기술 스택, 가용 시간대 등) 설정 
* **팀 빌딩 시스템:** 프로젝트 모집 게시글 작성, 조건별 팀원 검색 및 필터링 
* **포트폴리오 공유:** GitHub REST API 연동을 통한 실시간 레포지토리 및 이력 노출 
* **실시간 알림:** 매칭 신청 및 수락 여부 자동 알림 기능

## 📖 4. 문서화 및 품질 관리 (Documentation & Quality)
* **API Specs:** Flasgger를 활용하여 OpenAPI(Swagger) 기반의 인터랙티브 API 문서 제공
* **Tech Docs:** Sphinx를 통해 소스 코드 Docstring으로부터 기술 문서 자동 생성 
* **SSOT:** 코드 자체가 궁극적인 진실 공급원(Single Source of Truth)이 되도록 관리

프로젝트 기능 범위(MVP) 정의

1. 회원가입 및 로그인 기능

사용자는 이메일과 비밀번호를 이용하여 회원가입 및 로그인을 할 수 있다.
로그인 성공 시 JWT 기반 인증을 통해 사용자 세션을 관리한다.
사용자는 로그아웃 기능을 사용할 수 있다.

2. 프로필 작성 기능

사용자는 자신의 프로필 정보를 작성 및 수정할 수 있다.
프로필에는 관심 분야, 기술 스택, 협업 스타일 등의 정보를 포함한다.
사용자는 자신의 GitHub 링크를 등록할 수 있다.

3. 프로젝트 모집 게시글 기능

사용자는 프로젝트 모집 게시글을 작성할 수 있다.
게시글에는 프로젝트 제목, 설명, 모집 인원, 요구 기술 스택 등의 정보를 포함한다.
사용자는 게시글 목록 조회 및 상세 조회를 할 수 있다.

4. 팀 신청 및 수락/거절 기능

사용자는 원하는 프로젝트에 팀 신청을 할 수 있다.
프로젝트 작성자는 신청 내역을 확인할 수 있다.
프로젝트 작성자는 신청을 수락 또는 거절할 수 있다.

5. GitHub 포트폴리오 링크 연동 기능

사용자는 자신의 GitHub Repository 또는 프로필 링크를 등록할 수 있다.
다른 사용자는 등록된 GitHub 링크를 통해 포트폴리오를 확인할 수 있다.

추가 구현 기능

6. 프로젝트 검색 및 필터링 기능

사용자는 관심 분야 및 기술 스택 기준으로 프로젝트를 검색할 수 있다.
사용자는 조건별 필터링 기능을 사용할 수 있다.

7. 마이페이지 기능

사용자는 자신이 작성한 프로젝트 모집글 및 신청 내역을 확인할 수 있다.
사용자는 자신의 프로필 정보를 수정할 수 있다.
